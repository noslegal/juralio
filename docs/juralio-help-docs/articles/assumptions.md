# Assumptions

**Assumptions** are short notes attached to each phase that help to guide projected resource allocation and define the scope alongside deliverables.

* Up to 10 assumptions can be added per phase
  * Each has an optional name plus assumption text
  * You can do the following with them; Edit or delete them, and mark their status - **On target, At risk, Met** or **Not met.**

Rates and assumptions can be opened at any time from the **Rates** and **Assumptions** buttons on the cost dashboards.
