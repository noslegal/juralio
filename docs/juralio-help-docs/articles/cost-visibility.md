# Who can see costs

Cost information is sensitive, so what you see depends on your **position:**

* **Internal users** who have cost permissions get the full setup and editing experience.
* **External users** have sensitive details hidden -
  * E.g. External clients cannot see discount and reference-rate columns, and margin / profit / cost breakdowns - and see only their own agreed rates and finalised projections.
  * E.g External advisors
* External users cannot see any costs until it has been set up by the internal group
* Once set up, external users have view only permissions within the costs area
