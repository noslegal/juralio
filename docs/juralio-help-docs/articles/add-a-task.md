# Add a task

There are two ways to add a task

* Within the taskmap, hover over a task and use the + sign to add a sibling or subtask inline
* Press the add button (+) at the bottom of the screen, and you will see an option to add a task.
  * A dialog will ask you to name the new task. This will also guide you to position the task in the correct matter and workstream and with the correct parent task. If you are already in a workstream, assumptions will be made based on your current location, but you can change these if incorrect.

The new task is given a JUR-number which is unique to the matter. This cannot be changed and provides an unambiguous way of referencing the task. By contrast, task names need not be unique and may be changed.

The workflow status of a newly added task is *not started* (unless the parent task is already done, in which case a new subtask is assumed to have been done - but you can change its status if that's not the case)
