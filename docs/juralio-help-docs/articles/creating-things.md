# Creating things with the add button

Matters, templates, tasks, posts and other things in Juralio can be created using the add button - a + sign near the bottom of the bar on the left of the screen.

To add something new:

* Click the button
* A menu will appear showing you all the things you can create
* Some things can only be created when you are on the relevant screen

Depending on where you are in Juralio, we will make a best guess as to where the destination should be.

For example, if you add a post with task details open, we will assume you intend to post the post to that task. Press 'Edit' if that's not your intention.
