# Create a workstream

You'll need to be a matter admin. Go to the admin settings area (within the matter switcher) for the relevant matter. Then go to Workstreams.

There are three ways to create a workstream.

## Option 1: create a workstream from existing tasks

This option is only available if you have at least one existing active workstream with at least one task. If you choose it, you'll be asked to select a task from an existing workstream. This task (and its subtasks) will be moved into the new workstream automatically upon creation.

You can move further tasks between workstreams by selecting the relevant tasks and choosing "move" from the task options menu.

## Option 2: create a blank workstream

Create an empty workstream and add tasks to it yourself.

## Option 3: create a workstream from a template

Select this option when creating a workstream in the matter admin area. You can then choose the relevant template from a list.

Alternatively, you can start in the templates area. Choose the relevant template, press "use template" then select the matter (or create a new one) and, if the matter already exists, create a new workstream.
