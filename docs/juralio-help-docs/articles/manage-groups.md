# Create and manage groups

Creating, editing and deleting groups is an **organisation-level admin** action. It is available to:

* **Organisation admins** and **organisation owners** (within their own organisation)
* **System administrators**

Being a member of a group is not enough to manage groups. External accounts cannot manage groups.

From **Organisation admin** → **Accounts and groups** → **Groups** you can:

* **Add a new group** - choosing its name, default position, and an optional logo
* **Rename a group** - edit the name directly in the groups list
* **Change a group's default position** - switch between Client and Advisor. This affects only future matters; groups already added to existing matters are not changed
* **Add, change or remove a group's logo**
* **Delete a group** - but only when it has no active accounts. If people are still assigned to the group, the delete option is unavailable

The groups list also shows, for each group, the number of active accounts that belong to it and the number of open matters it has been added to.
