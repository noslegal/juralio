# Overriding block links

Blocked tasks should only be started once their blocker is completed.

## What if I need to start a task before then?

Blocks in Juralio are not strict. If a team member needs to start a task, editors can choose to override the block when the warning appears on status change.

## Scenarios where a block can be overridden

* Direct status change to the blocked task
* Indirect change to the status of the blocked task via either
  * parent/subtask
  * moving the task

Once the override is confirmed the blocks will no longer exist in the relevant tasks. Once confirmed this cannot be undone, blocks must manually be reinstated.
