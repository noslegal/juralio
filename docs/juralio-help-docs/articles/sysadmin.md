# Sysadmin

Only sysadmins can

* Create new organisations (relevant if you are in a complex corporate context in which segregated organisations are desired)
* Disable existing organisations
* Create new accounts
* Assign people to organisations
* Manage accounts (e.g. activating/deactivating them, changing permissions)

If you are a sysadmin, you will have access to further guidance (not available online) on the details of what you can do and see, and how to do it.
