# Create a workstream from a template

Go to the **Templates** area then

* open the **Template** you want to base the workstream on
* select the **Use template** button in the template overview screen
* follow the instructions

## Using part of a template

Yes, you can. Here's how

1. Go to the Template Gallery through the **Templates** button on the homescreen.
2. Open the template you want to use and select **Use template**.
3. Select the option to use a task from this template.
