# Organisation security settings

Organisation admins have the ability to enable or disable MFA and SSO for the entire organisation within the **security** settings tab.

With MFA enabled, org administrators can disable MFA at individual account level. That said, we recommend keeping it enabled.

See [**Manage accounts and groups**](./manage-accounts.md) to enable or disable SSO at individual account level.

## Documents (within Settings)

The **documents** tab allows organisation admins to enable or disable integrations with document systems such as Google Drive .
