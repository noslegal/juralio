# Reference numbers

Reference numbers in Juralio provide you with an unambiguous way to refer to a particular matter, template or task.

This is important because names may change and need not be unique.

## Matter numbers

There are two types of matter number:

1. The person creating a matter is asked for a reference number. This is for the number you use in your other systems (e.g. accounting or practice management system).
   This is the matter number displayed in the matter switcher and on most other screens.
2. Juralio also automatically assigns each matter a unique reference number, starting at 1 in each Juralio organisation. This is only visible to matter admins and organisation admins, in the relevant admin screens.

## Workstream numbers

Each workstream in a matter has an automatically assigned number, starting at 1 in each matter. You can see these numbers in the matter switcher and the workstream overview screen.

## Task numbers

Each task within a matter or template has a number.

This is displayed on the task with a #. For example, #123.

These numbers are unique to that **matter or template**.

Task numbers do not change if you move a task to another workstream within that matter.
