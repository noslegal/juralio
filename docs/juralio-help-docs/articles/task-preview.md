# Task preview

When hovering over a task in either the taskmap or roadmap, select the preview icon to preview the task details.

This allows you to:

* **View and edit**: dates, labels and the assigned team
* **View only**: the number of posts in the task and the task description
* **Select further to**: link dates, change status, add a post or go into the [task details](./task-details.md)
