# Restricted posts

By default, all posts (notes or links) are visible by anyone who is a matter editor on the matter.

A restricted post is only visible to its editors.

To make a new post restricted:

* Begin creating the post as normal through the add button (+) or the add post button
* Change **Visible** to **Restricted** in the top right of the creation dialog
* Finish creating the post as usual

To make an existing post restricted:

* You can only make an existing post restricted if you are a **Post Editor**
* Select the post in the post list
* Select the note options button (three dots) on the right hand side of the selected note
* Select **Make restricted** and finalise the post

You can turn off restricted status by changing the finalised post [back into a draft](./draft-and-final-notes.md) and toggling the switcher from **Restricted** to **Visible To All** and finalising once again.
