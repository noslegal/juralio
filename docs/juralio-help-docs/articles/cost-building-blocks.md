# Cost building blocks

## Grades

Positions or roles in a law firm or other organisation for which time is recorded (for example, partner or associate).

* Because there can be many grades, each with their own **hourly rates**, they are organised into larger grade categories to make estimating and analysis easier.
  * Juralio suggests some starter grades and categories which you edit to match your organisation.
  * Grades appear throughout Juralio in the order shown, and you can **drag and drop** to reorder them.
  * A grade that is already in use cannot be deleted.

## Rate types

Different types of rate which your organisation has for a given grade (for example, standard rate or target rate).

* Advisor costs have **five** rate types:
  * Standard
    * Break-even
    * Premium
    * Agreed - Client
    * Agreed - Matter
  * Client costs have **three** rate types:
    * Target
    * Agreed- Advisor
    * Agreed - Matter
  * Standard/Target, Break-even, and Premium can be renamed to match your organisation's own terminology (for example "benchmark" instead of "standard")
  * "Agreed" rate types cannot be renamed

## Other cost types

This allows you to define types of cost other than grades / rates (for example, travel, barristers, external expenses or disbursements, or fees for services such as technology access).

* Edit the list to reflect your organisation's needs
