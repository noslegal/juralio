# Organisation admin

People with the roles of organisation owner and organisation admin can access the organisation admin area.

You can reach this via the cog button near the bottom of the navigation bar on the left.

This area allows organisation admins to manage

* Individual accounts
* Matters (access and status)
* Labels (configuration)
* Settings (security and documents)
* Costs (grades, types and rates)

## Matters at organisation level

Organisation admins can see a list of all matters in their organisation. Clicking a matter in the list provides further details. They also have some matter-level permissions which can be useful for unblocking things:

* Close a matter
* Close or reopen a workstream within a matter
* Add or remove a matter admin

New matters can be created through the add button.
