# Create a matter

First you need to be a matter creator

* Matter creator is a Juralio role
* You can only create new Matters if you have it
* If you don't have it and think you should, speak to your organisation admin (e.g. your IT department)

Assuming you're a matter creator:

* Go to the home screen then select the Add button (+) and select Matter
* If you don't see that option, you're not a matter creator - speak to your organisation admin (e.g. your IT department)
* Choose the Position of the Internal group for the matter (see [Matter positions](./matter-positions.md))
* Enter the client/advisor name, matter name, matter number and optionally department name, then 'Create'

Things to bear in mind

* A new matter's initial status is active by default but you can deactivate it if you don't want anyone to work on it yet
* You're a matter admin by default on the new matter and (unless you stop being a matter admin) can add/remove other people as matter admins or team members
* If there is no available matter admin on a new matter, ask a system administrator to add you or someone else as a matter admin so that you can unblock things
