# Set up single sign-on (SSO)

As an organisation administrator:

* Go to the organisation settings area via the cog icon in the left hand navigation to enable SSO
* You can now switch accounts to SSO within the **Accounts** tab.
  * Before switching, check the correct email is attached to an account (e.g Google) otherwise access will be lost
* You will also have the option to invite new accounts as SSO logins

Juralio accounts can only have one method of authentication e.g. Google SSO **or** Juralio password not both.
