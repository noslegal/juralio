# Task details

Every task in a Juralio can be opened by clicking to reveal further details.

The background colour of the task details indicates the current status of the task.

## Task details - heading and above the heading

At the top left of the task details panel is a heading containing

* the task's name, level indicator (A to F) and reference number
* on the right hand edge, an option button (three dots) allows you to
  * [copy](./move-copy-tasks.md) the task or (if you're a matter admin) [move](./move-copy-tasks.md) it,
  * rename or [archive](./archiving-and-closing.md) it,
  * change the status,
  * download the details as a word document

Whenever you're viewing task details, you can also choose to navigate to its context in taskmap or roadmap by pressing the appropriate button at the top of the screen. This is useful if e.g. you navigated to task details from the recent tasks list in your home screen but now wish to see the task in its roadmap context.

## Task details - overview

By default the task overview will be open when first clicking into it . This contains the following information

* Key dates
* Task description - add a few words to remind people of key points about this task
* Task team members and followers
* [Task labels](./labels.md)

## Task details - posts

A preview of the task posts is given in the middle panel of the task details.

Selecting a post will open it up further to view the contents and allow editing.

## Subtasks

To the right of the task's posts, you can see the task's immediate subtasks. You can navigate to those by clicking on them.
