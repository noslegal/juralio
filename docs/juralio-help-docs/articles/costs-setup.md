# Set up organisation costs

Before your teams can estimate and price matters, your organisation needs to set up its cost building blocks and rate tables.

This is a one-time setup (which you can adjust later) in **Organisation admin** → **Costs**.

The Costs area only appears when the costs feature has been enabled for your organisation in sysadmin. Setting it up is an organisation administrator task.

## Who can set up organisation costs

* **Organisation administrators**, and only when the costs feature is enabled for your organisation within Sysadmin.
* Until organisation costs have been set up, there will be no option to add cost permissions within a matter

## Client or Advisor

Inside the Costs area there are two sub-tabs - **Client** and **Advisor**. Set up for each is individual as rates and terminology differ between positions. (See [Matter positions](./matter-positions.md) for what Client and Advisor mean.)

## The setup

The first time you open Costs, a guided setup walks you through it:

1. Learn about Juralio cost building blocks
2. Define your organisation's blocks
3. Build your first rate table, using those blocks

If you leave partway through, a "**Welcome back**" screen lets you continue where you left off.
