# Roadmap

The roadmap shows the timeline of a workstream. You can expand further into subtasks and vary the timescale displayed.

## Roadmap at a glance

The initial roadmap view shows:

* each phase
* a blue vertical line for today's date
* the start and end dates (if any) for each task
* levels of subtask for each phase (shown as grey arrows to the left of each task)
* the same information about each task as in taskmap (e.g. people, status)

## Interacting with the roadmap

You can do these things with the roadmap:

* The same things you can do on the taskmap for each task (e.g. change its status and dates)
* Change the time scale of the roadmap (e.g. entire workstream, year, quarter, month)
* Expand and collapse each task to show or hide its subtasks using the grey level indicator arrows to the left

### Expanding and collapsing the roadmap

There are two options for viewing the subtasks of a phase

1. Expand all:
   To view all subtasks in the phase, use the **expand all** button that appears at the end of the grey arrows on hover

   You can also **collapse all** to show just the phase again.

2. Expand level-by-level:
   Hover over the level indicator arrows to the left and select the level you want to expand to.

   To **collapse** subtasks again, press the parent level indicator.
