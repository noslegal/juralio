# Manage individual accounts

The **Accounts** tab allows organisation admins to manage individual user accounts. Here, admins can see how many seats are available in their organisation to assign accounts to.

New accounts can be added to the organisation through the **Invite someone** button.

Existing accounts can be made active or inactive from the accounts table.

Clicking a user's profile in the table allows you to

- edit their name and organisation
- edit association and Juralio roles: see [**Account types and roles**](./account-types.md)
- choose their authentication method (password or SSO): for details, see [Logging in](./logging-in.md)
- resend their email invitation (enabling them to change their password if using that method of authentication)
- reset their tutorial cards and feature reminders
