# Add or remove a matter editor or admin

Only matter editors can see and work on the contents of workstreams.

You need to be a matter admin to add or remove a matter editor.

You need to be a matter admin or org admin to add or remove a matter admin.

Assuming you are a matter admin -

* Select the matter you wish to add someone to from either the Home Screen or the Matter switcher
* Select **Administer this matter** then **People**

**Remember**: sysadmins cannot be matter editors or matter admins.
