# Client costs

Client costs differ from advisor costs within matters as clients can only have a fixed fee projection. This has a less fluid, step-by-step setup flow when creating projections:

1. **Period & Currency** - choose the projection period and the currency the arrangement will be billed in.
2. **Fee Type** - enter the total fixed fee for the whole matter for this period and set the rules for out-of-scope work
   * whether written approval is required if extra work arises and,
   * how such work is priced
     * fee must be expressly agreed
     * default to hourly rates
     * Custom
   * If hourly rates are chosen, these can be taken from a rate table or entered manually
3. **Review Scope** - review the matter's phases grouped by workstream
   * Juralio warns where phases lack assumptions or deliverables as these contribute towards meaningful scope
   * Assumptions and deliverables can be added from here
4. **Final Review** - a read-only summary of the fixed fee, scope and out-of-scope terms. Selecting "Confirm arrangement" applies it to the matter and takes a snapshot (see below)

## The Client costs dashboard

Once at least one fixed fee is finalised, the cost dashboard tracks the fees against the work actually being done. From here you can open the matter's assumptions, set another fixed fee (a follow-on projection), and see each projection as a card (drafts can be resumed; finalised ones can be retired).
