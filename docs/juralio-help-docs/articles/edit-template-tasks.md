# Edit a template's tasks

You need to have the knowledge manager role to do this.

Go to **Templates** and select the relevant template card.

This will take you into the template's overview. You will see that this is similar to the taskmap within a workstream, but the colour scheme is different, as a reminder of where you are.

You can navigate the taskmap in the same way as within a workstream.

You can edit a template task's name or description as in a workstream.

You can also add posts to provide useful information to people using the template e.g. legal materials or detailed guidance on relevant issues.

## Moving and copying tasks within a template

Tasks can be moved and copied within a template in a similar way to workstream tasks:

* To **move** a task within the current template, either drag and drop it within the template task map or use the task options menu and select "move."
* To **copy** a task within the current template or to another template, use the task options menu and select "copy." Alternatively, if you want to use **all** of a template's tasks as the basis for a new template, go to the original template and select "Copy" from the template options.
