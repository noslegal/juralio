# Restricted workstreams

Restricted workstreams can be created within matters by [matter admins only.](./matter-permissions.md)

## What are restricted workstreams for?

A restricted workstream within a matter is like a regular workstream, except that access to it is restricted to people nominated by the matter admin(s).

This is useful for a management team or other sub-group to handle more sensitive topics within a smaller group, while keeping the workstream within the context of the matter to which it relates.

## Creating a restricted workstream

Matter admins can select the option to make a workstream restricted in the admin settings of the matter. This can be toggled on and off as desired.

## Who can see restricted workstreams?

All admins in a matter can see a list of restricted workstreams within the matter admin.

Only people added to the restricted workstream by matter admins can see the contents of the restricted workstream.

Any matter admin can add or remove someone to or from any restricted workstream within the matter, i.e. restricted workstreams are *not* exclusively controlled by a single matter admin.
