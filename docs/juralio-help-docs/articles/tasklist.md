# Tasklist

The tasklist allows you to see all of a workstream's below-phase-level tasks (i.e. level B and lower) in a single list. This is useful because you can order the list by priority, independent of the taskmap ordering.

Drag and drop tasks to reprioritise them.

## Filtering the tasklist

Filters allow you to curate the list view further.

You can filter by:

- Task level (B, C etc)
- Phase the task belongs to
- Status of task: default is not started (NS) and in progress (IP) tasks
- Only showing milestones or deliverables - e.g. to obtain just an overview
- End dates before or after a date which you specify - e.g. to show just the next week or month's deadlines
- Assigned team members - e.g. to help redistribute work

## Ordering the tasklist

The tasklist can be ordered in three ways

* Custom - you can drag and drop items independently of their taskmap ordering. This is specific to you and doesn't affect the tasklists other people see.
* Taskmap order.
* End date order - tasks with the earliest end dates are at the top of the list and undated tasks are at the bottom.
