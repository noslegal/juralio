# Cost snapshots

When you finalise a projection or fixed fee, Juralio takes a **snapshot** - a point-in-time capture of the rates, periods and assumptions exactly as they were at that moment. The live matter can change afterwards, so Juralio shows the two clearly:

* **Snapshotted data** (frozen when the projection was finalised) is labelled, e.g. "Rates snapshotted on {date}" / "Assumptions snapshotted on {date}".
* **Live data** reflects the current state of the whole matter.

Finalised projections can be **retired**, and shown again via the "Show retired projections" toggle.
