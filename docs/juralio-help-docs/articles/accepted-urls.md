# Accepted URL types

The following is a list is URL links that are currently accepted within Juralio:

* Standard web URLs, e.g. `https://www.example.com`
* IPv4 addresses, e.g. `192.168.1.254`
* IPv4 addresses with a port, e.g. `192.168.1.254:8000`
* Arbitrary host names with a port, e.g. `http://localdocumentstorage:8080`
* iManage unc links

All URLs support path & url parameters.

## Adding a link that isn't on this accepted list

If you need to add a link specific to your organisation that isn't currently accepted by Juralio, contact {{support_channel}} to request that it be added to the accepted URLs.

New link types typically take a week to be updated after requested in Juralio.
