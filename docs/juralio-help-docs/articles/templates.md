# Templates

You need to be a knowledge manager to create, publish or unpublish a template.

* Only knowledge managers can see **unpublished templates**.
* Everyone in your organisation can see **published templates**.

A template can be created from scratch. For convenience, you can also create a template from the task names and structure of an existing workstream (dates, posts, team members and other data will not be copied from the workstream which you do this).

To create a template:

* go to the **Templates** area
* click the add button (+) and select **Template**
* follow the instructions
