# Draft and final notes

Notes have a workflow status: draft or finalised.

When you create a new note it will be a draft by default. Finalised notes will display differently in the notes list and cannot be edited unless first moved back to a draft state.

To change the status of a note:

* Select the note you want to finalise within the task details list
* Select the **FINALISE** button to mark a draft post as final
* Select the **EDIT** button to mark a finalised post as a draft and continue editing.

## Post authors

Each post has at least one author. Others can be added voluntarily. This signifies who wrote the post. It also determines who can see it if it is made restricted (below).

## Who can see a draft

Draft notes can only be seen by **authors**, final notes can be seen by all matter viewers unless made restricted.
