# Organisation-level roles

Accounts may have any number, or none, of the following organisation-level roles

* **Organisation owner** - this has all the permissions of an admin, with the additional responsibilities of managing the organisation's [seats and subscriptions](./organisation-admin.md). Each organisation can have up to three Org owners. The individual that initially set up the organisation will automatically be given the Org owner role.
* **Organisation administrator** - this allows you to add / remove organisation accounts, manage multi-factor and single sign on authentication, reset passwords and add / remove organisation admin and matter creator roles
* **Matter creator** - this allows you to create matters
* **Knowledge manager** - this allows you to create, edit and (un)publish templates
