# Team members and followers on tasks

Task team members give an indication of the people responsible for a task. All task team members will receive notifications in their inbox when any changes are made to the task. You can assign yourself as a team member or you can search for another person in the matter to assign them.

If you would like to receive notifications on task changes without indicating yourself as responsible for the work you can add yourself as a task follower. You can only assign yourself as a follower and not other people.

You can only edit data in a matter if you have editing permissions.

Find out more about matter permissions [here](./matter-permissions.md).

## Adding and removing team members

To add your first team member to a task:

* Select the add user icon on the task card (in taskmap or roadmap) or in task details.
* A list of accounts in the matter will appear. Select who you want to add.

To add a second (or subsequent) person to a task:

* Click on the first person's icon on the task card (in taskmap or roadmap) and the option to add will appear, or
* Open task preview or task details and use the 'Add team member' button

To remove a team member

* select the user icons in the task preview or task details.
* this will open up a list of all the task team members and their roles
* select X to remove them from the task

**Note:** removing a task team member will mean they will no longer receive notifications for the task and it will not appear in their To do list.

## Add people to multiple tasks

To assign people to all of a task's subtasks (direct or indirect) by:

* Selecting the user icons in the [task preview](./task-preview.md)
* This will open a list of people on the task
* Select the 'Add to subtasks' button beside the relevant person
* They will be added to all existing subtasks

**Note:** if more subtasks are created in future, we **don't** automatically add the person previously added to other subtasks.

To remove someone from a task and all its subtasks

* Select the user icons in the [task preview](./task-preview.md)
* Select the 'X' to remove the person - if they're also on one or more subtasks, you'll see an option to remove them from just this task or also from its subtasks
