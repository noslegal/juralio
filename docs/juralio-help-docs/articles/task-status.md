# Task status and colours

Juralio has a deliberately simple workflow for tasks, represented by colours.

**Light yellow**- not started

**Yellow** - in progress

**Teal (green-blue)** - done

More complicated workflows are achieved in Juralio by breaking a task into suitable subtasks.

There is also a fourth colour:

**Grey**- not required

* This is for tasks which you don't expect to need but which you'd like to keep within the taskmap structure instead of archiving them.
