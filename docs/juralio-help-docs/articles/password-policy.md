# Password policy

**The password policy for Juralio users is:**

* Minimum 15 characters with complexity applied.
* Complexity in this case means a minimum of: one upper case letter, one lower case letter, one number, one special character.

**Password guidance:**

* You may choose to use a password manager to store your passwords. This can avoid the need to remember multiple passwords, and the password manager may provide a feature to randomly generate passwords that meet length and complexity requirements.
* Avoid reusing passwords on multiple accounts
* If creating your own password, consider using three random words to achieve longer password lengths
