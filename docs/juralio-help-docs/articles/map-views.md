# Filtering, zooming and view options

## Filtering

Use filters to help you analyse your work and find what you're looking for.

The following filters can be found at the **top right** of the taskmap and roadmap.

**Status filters:** **Done** tasks are automatically filtered out of maps to keep you focused on what's to come. These can be filtered back into the map using the status filter.

**Task type filter:** You can choose to see just milestones or just deliverables so as to focus attention on these important elements.

**Label filter:** use this filter to highlight the tasks that have labels attached to them e.g. all tasks in the workstream that are currently awaiting approval.

**Assigned team members / people filter:** find out what tasks you should be working on, what each team member has been assigned to, and what tasks are currently unassigned.

When filtering by task type, label or people, relevant parent tasks are shown (faded out) to give you a sense of where the filtered-in tasks are in the hierarchy.

## Standard, compact and detailed views

Taskmap and roadmap views in matters have three different levels of detail

* **Standard** is the default view and includes a summary of dates, team members and the number of posts on each task
* **Compact** hides dates, team members and post numbers so that you can see more tasks on screen.
* **Detailed** allows you to see labels. It is only available if there are in fact some labels.

Change these views options via the control which sits just above the minimap at the bottom-right of the screen.

Templates have only the **compact** and **standard** views (no detailed view). Compact is the default. Choose standard if you want to see the number of posts on each card.

## Zooming

**Taskmap** in matters or templates can be zoomed between 30% (zoomed out) and 120% (zoomed in). The default is 100%.

Zoom using the on-screen buttons at the the bottom-right of the screen. You can also control zoom on the keyboard via ctrl + or ctrl -. If using a Mac, command + or - will also work.

**Roadmap** can also be zoomed using the buttons at bottom right. There are five zoom levels: entire, year, quarter, month or week.

## Minimap

The minimap at the bottom-right of the screen on taskmap and roadmap tells you where you are on a larger map. You can drag the pale window within the minimap to change your location on the larger map.
