Juralio API summary

Version: 2022. 9

Terminology

Sys Admin System Administrator Overall admin control of instance, organisations and users but no access to matter content.
Org Admin Organisation Administrator Admin control of a particular organisation, its users / roles / content.
MTM Matter Team Member Can see and edit a specific matter.
MA Matter Administrator Admin control of a specific matter (including e.g. access, archiving).
