# Installation

npm install -g .

Note this requires admin on windows.

## Usage

### React Component

jurcomp -n Widget

Generates Widget.js and WidgetContainer.js

### DataTable

jurcomp -n MonkeyTable -c Name,Age,Height,Bananana

Generates:
monkeytable-data-provider.js
MonkeyTable.js
MonkeyTableContainer.js
